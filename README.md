# oposCaib — Auxiliar Administrativo (CAIB)

Material de preparación de la parte práctica (Word y Excel) de la oposición de
Auxiliar Administrativo de la Comunidad Autónoma de las Illes Balears.

## Estructura

```
oposCaib/
├── Word/            15 supuestos prácticos de Word
├── Excel/           10 supuestos prácticos de Excel
├── Practica_Word/   ejercicios de práctica extra de Word
├── Practica_Excel/  ejercicios de práctica extra de Excel
├── Teoria/          temario y material de referencia
└── Tests/           tests teóricos
```

Cada carpeta `Supuesto_NN` contiene normalmente:

- **`...ENUNCIADO.pdf`** — el ejercicio a resolver.
- **`...RESUELTO.pdf` / `...SOLUCIONES.pdf`** — la solución.
- **Guía / Paso a Paso** — explicación de cómo se hace.
- **Archivo de datos** (`.docx` / `.xlsx`) — para practicar sobre él.

> Los supuestos numerados 1–25 forman una única serie; el número no indica el tema:
> cada uno mezcla varias técnicas. Algunos enunciados están en catalán y otros en
> castellano.
